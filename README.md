# HenuBCI

## HenuBCI 能做什么

HenuBCI 是面向实验室与课题组的自托管协作平台。成员可以查看彼此的课表、找到共同空闲、组织项目小组，再通过任务、成果与工作记录持续交流进展。工作关系图提供另一个入口：从一个成员出发，查看他参与的小组、承担的任务及已有工作来源。

没有管理员角色。所有注册成员权限平等，自己的课程与工作自己维护，任务由发布者管理和验收。

| 场景 | 使用方式 |
| --- | --- |
| 约讨论、安排实验 | 查看成员课表，查询多人共同空闲；小组课表可叠加查看 |
| 整理个人课表 | 手动编辑，或从表格、河大教务、课表图片导入；确认预览后才写入 |
| 推进课题协作 | 创建公开或指定任务，提交成果、上传资料，由发布者验收 |
| 分享当前进展 | 发布“正在做的事”，保留进行中、暂停及完成记录 |
| 了解工作联系 | 在沉浸式关系图中浏览成员、小组、任务、工作记录与来源 |

## 沉浸式工作关系图

进入关系图后，整页作为画布使用。节点从紧凑布局自然展开并逐渐稳定，连接较多的节点更大；不通过虚构关系让图谱看起来更密集。

| 操作 | 效果 |
| --- | --- |
| 鼠标滚轮／手机双指 | 缩放画布 |
| 拖动空白处 | 移动画布 |
| 按住节点拖动 | 调整节点位置，相邻节点自然响应，不选中文字 |
| 悬停或选中节点 | 高亮相连的细线与节点，查看来源详情 |
| 右上角设置 | 搜索及筛选范围，调整配色、节点大小、线宽与布局力度，重播展开动画 |

默认配色为成员绿色、工作记录红色、任务紫色、小组橙色。文字位于连线上方，节点保留完整圆形；普通关系采用浅灰细线，关联高亮采用紫色。

**关系有明确来源。** 已知成员、小组、任务和工作记录的关系使用实线；当前学期课程名称、时间、教室一致且周次相交时，可形成同课关系，这不代表实际到课。DeepSeek根据进行中／暂停工作和进行中任务分析内容联系，以虚线呈现；点击可核对理由和两端文字依据，也可提交“不准确”反馈。没有充分依据时，不为增加连线数量强行建立关系。

图谱与来源仅对已登录的启用成员开放，允许查看现存历史来源。它不会扩大原成员页的近期工作读取范围，也不会赋予修改他人记录的权限。删除来源或数据版本变化后，旧关联结果失效。

## 访问与权限

| 身份 | 可以查看 | 可以维护 |
| --- | --- | --- |
| 游客 | 脱敏课表、共同空闲、小组及受限任务列表 | 无写入权限 |
| 注册成员 | 成员课表、小组、任务详情、允许范围内的工作与关系图 | 本人课程、本人工作及本人发布的任务；按任务身份提交成果 |

私有附件下载须鉴权，不放入公开目录。消息清理只删除本人已读通知，不删除任务、成果、附件或业务历史。

成员只能修改本人课程和工作记录；仅发布者管理、验收自己的任务。游客只能查看脱敏课表、小组、空闲结果和受限任务列表。

## 本地运行

需要Node.js 24、PostgreSQL 17。从项目根目录执行：

```bash
cd web
npm ci
cp .env.example .env
# 填写数据库及认证配置
npm run db:migrate
npm run db:seed
npm run dev
```

打开`http://localhost:3000`。千问识别可选；所有导入先预览，再由本人确认。图片和教务密码不持久化。

`.env.example`仅是模板，请在本地`.env`填写数据库、认证及所需服务配置，真实密钥不要提交Git。关系图与自动分析采用独立开关，代码默认均关闭：

```dotenv
V3_GRAPH_ENABLED=1
V3_ANALYSIS_ENABLED=0
```

上述配置用于本地开启关系图并保留自动分析关闭。正式站已配置独立DeepSeek凭据，图谱和自动分析均开启；本地如需启用分析，先填写`DEEPSEEK_API_KEY`与`DEEPSEEK_MODEL`，完成验收后将`V3_ANALYSIS_ENABLED`设为`1`并重启服务。配置与分析启用条件见[V3.1需求](docs/12-PRD-v3.1.md)，不要复用图片识别凭据。

## 验证与部署

```bash
npm run lint
npm test
npm run test:integration
npm run build
```

以上命令在`web/`运行。集成与浏览器测试需要本地隔离 PostgreSQL（`127.0.0.1:5433`）及`POSTGRES_PASSWORD`配置，不应指向正式数据库。浏览器检查还需安装 Playwright Chromium，并指定已构建目录，例如在 PowerShell 中运行：

```powershell
npx playwright install chromium
$env:NEXT_DIST_DIR = ".next"
npm run test:tasks-browser
npm run test:graph-browser
```

GitHub CI执行代码检查、单元测试、生产构建和PostgreSQL集成测试；本地构建、CI通过及正式部署验收是不同验证阶段。最新测试数量和证据见[任务清单](docs/07-TASKS.md)。

生产采用腾讯云、Docker Compose和Caddy HTTPS。本地/CI构建Linux镜像，服务器只加载运行；发布前备份数据库及附件，禁止删除数据卷。CI检查代码；容器交付工作流发布镜像，不自动部署服务器。
