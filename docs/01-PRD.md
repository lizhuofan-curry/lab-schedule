# 同频课表产品需求文档（MVP-A 基线与后续路线）

版本：1.5
状态：MVP-A、MVP-B 与 v1 图片识别已验收；v1 项目小组已部署，本地完整验收与生产游客冒烟通过
日期：2026-10-01

## 1. 产品目标

为实验室成员提供一个易上手的网页工具，用于：

1. 查看任意已注册成员在指定教学周的课表。
2. 查询某天全天没课或指定节次没课的成员。
3. 选择多位成员或全体成员，查找可用于分配任务、讨论和开会的共同空闲时间。
4. 让每位成员直接在网页上维护自己的课表，不强制上传 Excel。
5. 按年级筛选成员和课表，并提供面向个人、多人和时间段的丰富空闲检索。
6. 后续支持从教务系统资料和课表图片中辅助导入，减少重复录入。
7. 允许成员建立项目小组、维护组长与组员，并按小组快速查询共同空闲。

系统不在 MVP-A 中管理任务内容、会议室、通知、教务数据导入或图片识别；后两项进入后续版本路线，不阻塞当前版本上线。

## 2. 用户与权限

### 2.1 成员

- 使用真实姓名、唯一学号和自设密码直接注册；无需预先录入名册。
- 使用学号和密码登录。
- 查看所有启用成员的课表、课程详情和空闲状态。
- 查看实验室名册的注册进度和未注册名单。
- 只可新增、修改、删除自己的课程。
- 可创建小组；创建者成为组长，组长可改名、维护组员、转让组长和解散小组。
- 不可查看他人的账号资料、操作日志或源文件。

系统不设置管理员账号或角色，所有注册成员权限平等。已有名册记录可在注册时自动绑定；新学号会自动创建成员记录。学期和节次仍作为部署初始化数据维护，不提供日常管理后台。

### 2.2 匿名用户

- 未选择游客模式时只能访问登录和注册页面；进入游客模式后可只读查看总览、成员课表和空闲查询。
- 可只读查看总览、启用成员课表、空闲结果和项目小组；学号脱敏。

## 3. 分阶段范围

### 3.1 MVP-A：首个可上线版本

- 部署时初始化学期和节次；已有实验室成员记录可以保留，但不是注册前提。
- 姓名＋唯一学号＋密码开放注册；学号＋密码登录；提供游客只读访问。
- 注册统计与未注册名单复制。
- 学期、教学周和每日节次时间配置。
- 网页直接新增、编辑、删除本人课程。
- 必填、周次、节次和时间冲突校验。
- 查看任意成员的周课表。
- 查询全天没课、指定节次没课的成员。
- 查询多人的共同空闲和至少连续 N 节的时间段。
- 服务端权限校验、关键操作审计、响应式布局。
- PostgreSQL 持久化、Docker Compose、Caddy HTTPS 和备份脚本。

### 3.2 MVP-B：批量导入与版本

- 按成员类别查看和筛选课表及空闲结果；当前规则为学号 `25` 开头显示“大二”，`24` 开头显示“大三”，其他学号统一显示“研究生”。
- 查询某位成员在指定教学周、星期和时间范围内何时有空，以及每段空闲持续多久。
- 按年级、成员、教学周、星期、起止时间和最短空闲分钟数组合检索。
- 支持“给定时间找空闲成员”“给定成员找空闲时间”“多人共同空闲”三类检索入口。
- 固定模板 `.xlsx` / `.csv` 下载与上传。
- 解析、逐行校验、冲突提示、预览、差异确认。
- 用户确认前不修改当前课表。
- 确认整表替换时生成不可变的完整课表 Snapshot。
- 历史版本和 Diff 只读查看；不提供一键回退。
- 支持从 Excel 或教务结果页复制带表头的课表表格，识别常见列名和组合上课时间，预览确认后导入。

### 3.3 v1

- 任意表头映射、`.xls`、完整版本回退。
- 从教务系统导出的文件、复制的文本或页面表格辅助导入课表。
- 支持输入河大学号密码，经统一身份认证自动同步课表（见 4.9 与 [08-河大教务系统接口.md](08-河大教务系统接口.md)）。
- 上传课表截图或照片，通过图片识别生成待确认课程草稿；低置信度字段必须醒目标记并由本人修正。
- 停课、补课、调课和调休。
- 成员分组、标签、导出和受控分享链接。
- 项目小组：任意注册成员可创建，一人可加入多个组，组长维护名称与成员，小组可直接用于共同空闲筛选。
- 更完整的审计和公开范围配置。

### 3.4 暂不实现

- 自动建会、通知和会议室预订。
- 未经本人确认直接覆盖现有课表。
- 自动选课 / 退课 / 抢课（同步仅只读抓取课表，不提交任何选课操作）。

## 4. 核心流程

### 4.1 注册

成员输入真实姓名、唯一学号和密码即可注册。若该学号对应未绑定的已有名册记录，系统更新姓名并绑定账号；若不存在则自动创建启用成员。一个学号只能注册一次，并发注册只能有一次成功。游客不创建账号或成员记录，仅获得短期只读访问标记。

### 4.2 网页维护课表

成员进入“我的课表”，点击空白格添加课程，点击课程卡片编辑；填写课程名、星期、节次和周次，教师、地点、备注可选。保存成功后，其他成员看到的课表与空闲状态立即更新。

#### 4.2.1 当前学期固定上课时间

当前学期为 `2026–2027 学年第一学期`，第 1 周从 `2026-08-31` 开始，共 18 周。网页和数据库必须使用以下时间，不得自行推算或调整：

| 节次 | 时间 | 节次 | 时间 |
| --- | --- | --- | --- |
| 第1节 | 08:00–08:45 | 第8节 | 15:55–16:40 |
| 第2节 | 08:55–09:40 | 第9节 | 17:00–17:45 |
| 第3节 | 10:00–10:45 | 第10节 | 17:55–18:40 |
| 第4节 | 10:55–11:40 | 第11节 | 19:10–19:55 |
| 第5节 | 11:45–12:30 | 第12节 | 20:05–20:50 |
| 第6节 | 14:05–14:50 | 第13节 | 20:55–21:40 |
| 第7节 | 15:00–15:45 |  |  |

`12:30–14:05` 为午休时间，不创建“中午1节”或“中午2节”，也不可在课程表单中选择。数据库只保存第 1–13 节。

### 4.3 查看成员课表

登录成员从成员列表搜索并选择一人，再选择学期与教学周，系统只显示该周实际生效的课程。

### 4.4 查找空闲

用户选择日期、成员范围和需要的连续节数。系统计算当天有效课程占用，返回全天没课成员、指定节次没课成员及所有被选成员的共同空闲连续区间。

### 4.5 按年级查看（MVP-B）

成员列表、课表总览和空闲查询增加“全部 / 大二 / 大三 / 研究生”筛选。当前学号规则为：`25` 开头对应大二，`24` 开头对应大三，其他学号归入“研究生”；该分类不得限制注册、课表维护和导入能力。

年级名称必须由“当前学年 + 入学年份规则”集中配置，不能把“大二”“大三”永久写死在多个页面中。当前展示映射以本节明确规则为准，后续学年只调整集中配置。

### 4.6 增强空闲检索（MVP-B）

提供三种容易理解的查询方式：

1. **查某人何时有空**：选择一位成员、教学周和星期，返回每段空闲的节次、实际起止时间和持续分钟数。
2. **按时间找人**：指定教学周、星期和起止时间，返回该时间段全程空闲的成员，并可按年级筛选。
3. **查多人共同空闲**：选择多位成员及最短空闲分钟数，返回所有人共同空闲的区间。

当前检索表单固定采用“单个教学周 + 单个星期 + 可选起止时间 + 最短空闲分钟数”，并支持年级和成员筛选。日期范围、节次范围和最少连续节数不属于当前交互；页面必须显示当前生效条件。

### 4.7 教务系统资料导入（v1）

已支持用户从 Excel 或教务结果页复制带表头的文本表格，识别常见课程列和“上课时间/上课地点”组合字段。系统完成解析后只生成待确认草稿，展示课程、星期、节次、周次、教师、地点、错误、冲突及与当前课表的差异；本人确认后才写入。任意学校专用导出文件格式继续按实际样例逐步适配。

如果后续确认学校提供合规且稳定的官方接口，可增加本人授权同步。不得要求用户把教务系统密码保存到本站，不得绕过验证码、反爬机制或访问控制；无法安全接入时继续使用导出资料辅助导入。

### 4.8 图片识别导入（v1）

用户可点击选择、从微信等桌面软件拖入，或复制后粘贴课表截图或照片；系统识别课程名、星期、节次、周次、教师和地点并生成可编辑草稿。拖放来源没有向浏览器提供真实图片文件时，页面必须明确提示用户改用复制粘贴或先保存原图。识别结果必须逐项预览，低置信度或缺失字段醒目标记；用户可修改、删除或补全后再确认导入。识别失败不得写入，重新识别不得覆盖已经确认的课表。

v1 提供两种识别方式：默认的服务器本地 OCR 不向第三方发送图片；可选的千问视觉模型用于提高彩色网格中星期、节次、周次和课程归属的还原准确率。选择智能识别前，用户必须明确同意把本次图片临时发送给模型服务。两种方式都只生成临时草稿，图片、OCR 原文和模型原始响应均不持久化；缺失或模型标为不确定的字段必须醒目标记，仍需经过人工校对、差异预览和本人确认才能写入课表。智能识别不可用时应给出可处理的错误，并允许用户改用本地 OCR。

### 4.9 河大课表自动同步（MVP-B 增量）

成员在「我的课表」临时输入河大统一身份认证密码；学号固定使用当前登录账号学号。系统登录 `xk.henu.edu.cn` 抓取本人课表，生成差异预览；成员核对课程名、节次、单双周和地点并明确确认后，才整表替换本人课表、创建 ScheduleVersion 和 AuditLog。

同步只读，不提供选课 / 退课；密码仅用于当前请求，不写入数据库、浏览器存储或日志。接口细节见 [08-河大教务系统接口.md](08-河大教务系统接口.md)。

### 4.10 项目小组（v1）

任意注册成员可以创建小组并填写名称，创建者自动成为组长。一个成员可以同时加入多个小组。只有当前组长可以修改小组名称、添加或移除普通组员、把组长转让给已有组员，或解散小组；普通组员不能修改小组。组长不能直接把自己移出，必须先转让组长。

所有成员和游客均可查看小组目录，游客看到脱敏学号且不能执行写操作。被停用成员不出现在小组目录和共同空闲计算中，但数据库保留其历史关系。小组可在“找共同空闲”中一键选择当前启用组员。创建、改名、成员调整、组长转让和解散全部写入 AuditLog。

## 5. 核心业务规则

- **BR-01 身份绑定**：一个成员最多绑定一个账号，一个账号最多绑定一个成员。
- **BR-02 学号唯一**：学号在整个系统中唯一，登录时大小写与首尾空格规范化。
- **BR-03 课程所有权**：成员只能写入自己的课程；所有权由服务端会话判断，不接收客户端指定的所有者。
- **BR-04 周次标准化**：单双周和范围只是输入形式，写入前必须转成具体教学周数组，如 `[1,3,5]`。
- **BR-05 时间冲突**：同一成员两门课程星期相同、周数组有交集且节次区间重叠时构成冲突，默认阻止保存。
- **BR-06 重复记录**：课程名、星期、节次、周次等完全一致为 Duplicate，不重复写入并提示。
- **BR-07 共同空闲**：共同空闲等于有效节次全集减去所有被选成员占用节次的并集。
- **BR-08 连续节次**：只返回共同空闲集合中长度大于等于 N 的连续区间，不能跨过被占用节次拼接。
- **BR-09 全天没课**：某成员在目标日期的有效课程集合为空，即为全天没课。
- **BR-10 学期边界**：目标日期不在学期日期范围内时不计算，返回明确提示。
- **BR-11 审计与版本**：网页 CRUD 写入 AuditLog；MVP-B 的确认批量导入生成完整 ScheduleVersion Snapshot。
- **BR-12 成员类别**：当前 `25` 开头学号归为大二，`24` 开头归为大三，其他学号显示“研究生”。类别映射集中配置，不通过姓名推断；该类别只用于筛选和展示，不影响注册、课表维护或导入权限。
- **BR-13 空闲时长**：空闲时长按所含空闲课节的真实授课分钟数累计，不把课间或午休分钟计入时长；相邻有效节次编号可显示为同一区间，当前交互不按日期范围检索。
- **BR-14 导入确认**：文件、教务资料和图片识别均先生成草稿与差异预览；只有当前登录成员明确确认后，才可写入其本人课表并记录审计。
- **BR-15 导入所有权**：导入接口仍由服务端会话确定课程所有者，禁止通过上传内容或请求参数替其他成员导入。
- **BR-16 教务凭据**：河大课表同步只接收当前登录成员的一次性密码；学号由会话确定，密码不持久化、不进入日志与客户端包。同步只读，不伪造选课提交、不绕过验证码、不做高频轮询。
- **BR-17 当前状态**：成员目录的“有课”仅表示北京时间当前时刻处于本人实际生效课程的起止时间内；只在当天有其他课程但当前不在上课时间时必须显示“空闲”。页面同步展示实时北京时间，避免状态含义不清。
- **BR-18 当前课表定位**：进入课表总览、我的课表和成员课表时默认展示北京时间对应的当前教学周；当前周中必须突出标记今天的表头与整列，窄屏横向课表自动滚动到今天。查看其他教学周时不得继续显示“今天”高亮。
- **BR-19 课表时间轴**：课表总览、我的课表和成员课表的每个节次标签都必须同时显示该节课的实际起止时间；紧凑模式和移动端不得只显示节次而隐藏时间。
- **BR-20 小组权限**：任意注册成员可创建小组且创建者为组长；一人可加入多个小组。只有当前组长可以改名、维护成员、转让组长或解散小组，所有操作由服务端会话校验并写审计。游客只读。

## 7. 易用性与状态

- 用户进入“我的课表”即可通过“点击空白格添加、点击课程修改”完成维护。
- 课程表单用自然语言标签，不要求理解数据库字段。
- 删除前二次确认；保存成功给出明确反馈。
- 空状态说明下一步操作；错误信息说明原因和解决办法。
- 手机端支持横向滚动课表，主要操作按钮可触达。
- 颜色不是唯一状态线索，课程卡同时显示文字。

## 8. 验收重点

### 8.1 MVP-A

1. 使用真实姓名、唯一学号和密码可直接注册；注册后成员目录和注册统计立即更新。
2. 已注册学号及同一学号的并发重复注册均被拒绝，且数据库只产生一个账号与一个成员绑定。
3. A 可以查看 B 的课表，但任何参数篡改都不能修改 B 的课程。
4. 同周同节冲突被阻止；不相交周次允许占用同一节次。
5. A、B、C 共同空闲只返回三人均无课的节次，连续 N 节算法结果正确。
6. 50 名活跃用户规模下主要查询保持流畅，至少使用 100 名成员、每人每学期 100 条课程做基础验证。
7. 桌面和手机浏览器均可完成注册、录课、查看和空闲查询；游客可只读查看总览、成员课表与空闲结果，且学号脱敏、所有写操作被拒绝。

### 8.2 后续版本

1. 学号以 `25` 开头的成员出现在“大二”筛选结果，以 `24` 开头的成员出现在“大三”筛选结果；其他学号显示在“研究生”，并可正常维护和导入本人课表。
2. 查询一位成员指定教学周、星期的空闲时，结果准确显示每段空闲的节次、真实起止时间和授课分钟数。
3. 按年级、教学周、星期、时间段和最短空闲分钟数组合查询时，返回成员均满足全部条件；清空筛选可恢复默认条件。
4. 教务资料导入可展示解析错误、课程冲突和与当前课表的差异；未点击确认前数据库不发生变化。
5. 图片识别结果允许逐项修改，低置信度字段有明显提示；识别失败或取消确认不会新增、删除或覆盖课程。
6. 所有导入只能写当前登录成员的课表，并生成审计记录；请求篡改不能替其他成员导入。
7. 输入一次性河大密码后可读取本人课表，抓取结果先预览后确认写入；密码不保存、不落日志，同步只读不选课。
8. 注册成员可创建小组并成为组长；普通组员不能改名或维护成员，组长转让后权限立即转移；游客只能查看。
9. 从小组页面进入共同空闲时，自动选中该组当前所有启用成员，结果与手动选择同一批成员一致。
