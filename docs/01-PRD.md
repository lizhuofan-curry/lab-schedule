# HenuBCI产品需求：课表与时间协作

本文件定义已实现的基础业务；任务和成员工作见[09](09-PRD-v2.md)，消息清理见[10](10-PRD-v2.2.md)，后续AI功能见[11](11-PRD-v3.md)。实际交付状态统一见[07](07-TASKS.md)。

## 1. 用户与权限

- 姓名、唯一学号和密码自助注册。已有未绑定名册则绑定，否则创建启用成员；并发重复注册只能成功一次。
- 注册成员可查看全部启用成员课表、注册进度；只能修改本人课程。学期和节次由部署初始化，无管理员后台。
- 游客不创建成员记录，只读查看脱敏总览、成员课表、小组、空闲结果及受限任务列表；不能读取注册进度、工作记录或私有任务资料。
- 普通匿名用户仅访问登录/注册；进入游客模式后才取得游客权限。

## 2. 已实现流程

| 功能 | 规则 |
| --- | --- |
| 本人课表 | 点击空格添加、课程卡编辑；课程名、星期、节次、周次必填，教师/地点/备注可选 |
| 成员与总览 | 搜索姓名/学号，按类别筛选；默认当前教学周、突出今天、显示各节实际时间 |
| 空闲 | 单教学周＋星期，可选起止时间及最短分钟数；支持某人何时空闲、按时间找人、多人交集 |
| Excel/CSV及复制表格 | 解析、逐行校验、冲突/差异预览、本人确认；整表导入创建只读快照 |
| 河大同步 | 会话学号＋一次性密码，只读抓取、身份复核、预览确认；见[08](08-河大教务系统接口.md) |
| 图片导入 | 点击/拖放/粘贴；本地OCR或经同意的千问识别；可修正草稿和低置信度字段，再预览确认 |
| 项目小组 | 任意成员创建并任组长；组长维护、转让或解散；多人多组可重叠，停用关系保留 |
| 小组课表 | 按周展示启用组员忙碌强度；同人同节只计一次，点击查看课程和空闲成员 |

所有导入未确认前不写课表，失败不覆盖已有数据；原图、OCR原文和模型原始响应不持久化。千问不可用时可回到本地OCR。拖放没有真实文件时提示粘贴或保存原图。

成员类别集中配置：当前学号25开头为大二、24开头为大三，其余为研究生；类别不限制注册或写入权限。

## 4. 核心业务规则

- **BR-01 身份绑定**：一个成员最多绑定一个账号，一个账号最多绑定一个成员。
- **BR-02 学号唯一**：学号在整个系统中唯一，登录时大小写与首尾空格规范化。
- **BR-03 课程所有权**：成员只能写入自己的课程；所有权由服务端会话判断，不接收客户端指定的所有者。
- **BR-04 周次标准化**：单双周和范围只是输入形式，写入前必须转成具体教学周数组，如 `[1,3,5]`。
- **BR-05 时间冲突**：同一成员两门课程星期相同、周数组有交集且节次区间重叠时构成冲突，默认阻止保存。
- **BR-06 重复记录**：课程名、星期、节次、周次等完全一致为 Duplicate，不重复写入并提示。
- **BR-07 共同空闲**：共同空闲等于有效节次全集减去所有被选成员占用节次的并集。
- **BR-08 连续节次**：只返回共同空闲集合中长度大于等于 N 的连续区间，不能跨过被占用节次拼接。
- **BR-09 全天没课**：某成员在目标日期的有效课程集合为空，即为全天没课。
- **BR-10 学期边界**：目标日期不在学期日期范围内时不计算，返回明确提示。
- **BR-11 审计与版本**：网页 CRUD 写入 AuditLog；确认批量导入生成完整 ScheduleVersion Snapshot。
- **BR-12 成员类别**：当前 `25` 开头学号归为大二，`24` 开头归为大三，其他学号显示“研究生”。类别映射集中配置，不通过姓名推断；该类别只用于筛选和展示，不影响注册、课表维护或导入权限。
- **BR-13 空闲时长**：空闲时长按所含空闲课节的真实授课分钟数累计，不把课间或午休分钟计入时长；相邻有效节次编号可显示为同一区间，当前交互不按日期范围检索。
- **BR-14 导入确认**：文件、教务资料和图片识别均先生成草稿与差异预览；只有当前登录成员明确确认后，才可写入其本人课表并记录审计。
- **BR-15 导入所有权**：导入接口仍由服务端会话确定课程所有者，禁止通过上传内容或请求参数替其他成员导入。
- **BR-16 教务凭据**：河大课表同步只接收当前登录成员的一次性密码；学号由会话确定，密码不持久化、不进入日志与客户端包。同步只读，不伪造选课提交、不绕过验证码、不做高频轮询。
- **BR-17 当前状态**：成员目录的“有课”仅表示北京时间当前时刻处于本人实际生效课程的起止时间内；只在当天有其他课程但当前不在上课时间时必须显示“空闲”。页面同步展示实时北京时间，避免状态含义不清。
- **BR-18 当前课表定位**：进入课表总览、我的课表和成员课表时默认展示北京时间对应的当前教学周；当前周中必须突出标记今天的表头与整列，窄屏横向课表自动滚动到今天。查看其他教学周时不得继续显示“今天”高亮。
- **BR-19 课表时间轴**：课表总览、我的课表和成员课表的每个节次标签都必须同时显示该节课的实际起止时间；紧凑模式和移动端不得只显示节次而隐藏时间。
- **BR-20 小组权限**：任意注册成员可创建小组且创建者为组长；一人可加入多个小组。只有当前组长可以改名、维护成员、转让组长或解散小组，所有操作由服务端会话校验并写审计。游客只读。
- **BR-21 小组课表总览**：成员或游客可按教学周查看启用组员的叠加课表；每个节次按“有课的不同成员数”显示忙碌强度，同一成员同节冲突课程只计一人。点击时间格必须列出有课成员、课程、教师和地点，并同时列出空闲成员。

## 6. 验收与边界

验证注册并发、A查看B但不能改B、课程重复/冲突、单双周、非连续空闲、跨学期和多人交集；导入须覆盖取消/失败不写库及本人所有权。小组验证普通组员不能管理、转让立即生效、整组空闲等同手选；桌面和390px完成核心流程。

100成员×100课程为基础性能测试规模；本地结果不代替正式持续负载验收。当前未实现其他学校专用登录解析、版本回退、调休/停补课、标签/导出/分享链接、自动建会或会议室预订。任务站内通知已实现，不归入这些延期项。
