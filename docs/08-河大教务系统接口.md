# 河大教务系统接口调研

版本：1.2
日期：2026-09-28


## 1. 概述

河南大学选课系统（`xk.henu.edu.cn`）是 Java 老式教务系统（Struts + JSP，接口以 `.action` / `.do` / `.jsp` 结尾，疑似正方教务）。登录走统一身份认证 IDS（CAS 单点登录），课表数据通过若干 JSP 接口返回。

本文用于支撑「输入学号密码 → 自动同步河大课表」功能的实现。**只做只读抓取**，不实现选课提交（提交参数加密、且越过用户确认属高风险，明确不做）。

## 2. 统一身份认证（IDS CAS）

### 2.1 登录入口

```
https://ids.henu.edu.cn/authserver/login?service=https://xk.henu.edu.cn/caslogin
```

`service` 参数指向目标系统（选课系统）。登录成功后 IDS 发放全局票据，重定向回选课系统建立会话。

### 2.2 登录流程（四步）

1. **GET 登录页**，从返回 HTML 中用正则提取两个隐藏值：
   - `execution`：`name="execution" value="..."`（会话 token）
   - `pwdEncryptSalt`：`id="pwdEncryptSalt" value="..."`（密码加密盐）
2. **AES 加密密码**（见 2.3）。
3. **POST 提交表单**（见 2.4）。
4. **换取会话**：IDS 下发 `CASTGC` / `TGC` Cookie → 重定向到 `xk.henu.edu.cn/caslogin` → 换到 `JSESSIONID`。

### 2.3 密码加密算法

河大 IDS 前端用 AES-CBC 处理本次登录提交（盐由页面下发）。这里是对认证请求的兼容处理，不代表本站会保存可解密的密码：

| 项 | 值 |
|---|---|
| 算法 | AES-128-CBC |
| 密钥 | `salt`（16 字符，直接作为 key） |
| 明文 | 64 位随机前缀 + 原密码 |
| IV | 16 位随机串 |
| 填充 | PKCS7 |
| 输出 | base64 |

随机串字符集（去易混淆字符）：`ABCDEFGHJKMNPQRSTWXYZabcdefhijkmnprstwxyz2345678`。

### 2.4 登录表单字段

| 字段 | 值 |
|---|---|
| `username` | 学号 |
| `password` | 2.3 加密后的密文 |
| `captcha` | 空（当前无验证码） |
| `_eventId` | `submit` |
| `cllt` | `userNameLogin` |
| `dllt` | `generalLogin` |
| `lt` | 空 |
| `execution` | 登录页提取 |

### 2.5 登录成功判定

登录成功后，选课系统会下发**学生身份**的 `JSESSIONID`。判定成功**不能只看是否拿到 JSESSIONID**——游客会话也有 `JSESSIONID`：

- 用 `GET /frame/home/js/SetMainInfo.jsp` 提取 `_loginid`。
- `_loginid` 非空且非 `guest` / `kingo.guest` 才算真正登录（`kingo.guest` 是游客降级，通常因登录失败或触发风控）。
- POST 表单应提交到**首次 GET 登录页后的最终 URL**（`response.url`），而非原始入口 URL。

## 3. 课表抓取

### 3.1 用户上下文

`GET /frame/home/js/SetMainInfo.jsp`，从返回的 JS 变量里提取：

- `_loginid`（学号 / 登录号）
- `_currentXn`（学年，如 `2026`）
- `_currentXq`（学期，`0` 或 `1`）
- `_userCode` / `_usertype` / `_schoolCode`

### 3.2 课表数据接口

| 用途 | 接口 |
|---|---|
| 我的课表入口 | `GET /student/xkjg.wdkb.jsp` |
| 课表网格数据 | `GET /student/wsxk.xskcb10319.jsp` |
| 课表列表数据 | `GET /wsxk/xkjg.ckdgxsxdkchj_data10319.jsp` |

参数统一为 `xn`（学年）+ `xq`（学期）+ `xh`（学号），以 base64 编码后通过 `?params=<base64>` 传递。

> 实测：直接访问数据接口返回「错误:无效访问请求」。正确流程：
>
> 1. 先 `GET /student/xkjg.wdkb.jsp`（我的课表入口页）建立上下文；
> 2. 从入口页 HTML 提取真实数据接口路径（`frmaction` 变量，或 `.jsp` 路径里含 `xskcb` / `ckdgxsxdkchj_data` 的）；
> 3. 用 `?params=base64("xn=…&xq=…&xh=…")` + `Referer: 入口页` 请求数据接口。

### 3.3 课表 HTML 结构（网格课表）

`xskcb10319.jsp` 返回一张网格课表（`<table id='mytable'>`，GBK 编码）：

- 表头为「星期一」~「星期日」7 列；每行**最后 7 个 `td`** 对应星期一到日（前 1–2 列是「上午/下午」时段与节次标签，含 `rowspan`）。
- 有课程的单元格是 `<div style='padding-bottom…'>`，内容结构为 `<font>课程名</font><br>教师 <br>周次 [节次]<br>地点`（按 `<br>` 分段）。
- 周次格式：`1-18`（全周）、`1-18 单`（单周）、`1-18 双`（双周）、`1-12`、`3-18` 等 → 转成具体周次数组（BR-04）。
- 节次格式：`[1-2]`、`[3-5]`、`[11-13]` → `startPeriod` / `endPeriod`。
- 无节次信息的课程（如「1-18周」的环节课程）不在网格中，页面底部另有一个「上课班级代码」列表（含 `[LDK…]` 环节课程），需另行处理。

## 4. 会话 Cookie

| 域名 | Cookie | 作用 |
|---|---|---|
| `ids.henu.edu.cn` | `CASTGC` / `TGC` / `happyVoyage` / `platformMultilingual` | CAS 全局票据 |
| `xk.henu.edu.cn` | `JSESSIONID` / `route` | 选课系统会话 |

## 5. 安全边界（实现必须遵守）

1. **凭据处理**：学号由当前会话成员确定，密码只存在于本次服务端请求内；不写入数据库、浏览器存储、日志、客户端包、仓库或截图。
2. **只读抓取**：只同步课表，不伪造选课提交参数、不实现退选/抢课。
3. **不绕过风控**：不识别验证码、不做高频轮询、不并发抢占。
4. **不固化敏感值**：`JSESSIONID`、`execution`、`salt`、`token`、`timestamp` 均为会话级临时值，不得写死到代码或文档。
5. **确认后写入**：抓取和解析只生成预览；本人再次确认后才通过统一导入事务替换课程、创建 ScheduleVersion/CourseSnapshot 并写 AuditLog。
6. **身份一致**：请求学号、当前会话学号和教务系统返回的 `loginId` 必须一致，否则拒绝生成预览。
5. **降级提示**：IDS 登录失败时给出明确提示，不做无限重试。
