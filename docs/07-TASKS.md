版本：1.2
日期：2026-09-28

本文把 MVP-A 与 MVP-B 拆分为可执行、可追踪的任务。状态基于 2026-09-28 的代码快照：`[x]` 表示代码已落地，`[ ]` 表示待完成或待验证。「代码落地」不等于「已验证通过」——验证项必须实际运行确认。
