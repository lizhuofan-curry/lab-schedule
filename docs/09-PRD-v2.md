# v2需求：任务协作与成员工作

任务、工作展示及资料预览已上线；当前进度和验收见[07](07-TASKS.md)。基础课表规则见[01](01-PRD.md)，接口/数据见[03](03-API.md)/[02](02-DATABASE.md)。本文件只维护最终业务规则。

## 1. 权限

| 身份 | 可执行操作 |
| --- | --- |
| 注册启用成员 | 查看全部任务、各轮要求、成果/反馈/附件；发布任务；领取开放公告 |
| 发布者 | 管理及验收本人任务：改要求、调目标、结束领取、打回/通过、撤销/重开 |
| 当前执行成员 | 共同模式提交本轮成果；逐人模式仅提交本人成果 |
| 游客 | 列表仅id/title/publisher/deadline/status/kind，无详情/成果/文件/消息/工作记录 |
| 匿名 | 无任务读取或写入权限，需登录或进入游客模式 |

无管理员、跨用户管理权或特殊录入人员；发布者也不能修改他人课程、记录或原小组。权限在服务端检查，不能只隐藏按钮。

## 2. 发布及领取

- 标题、要求必填；类型为公开（announcement）或指定（assigned），交付为共同或逐人，发布后不可更改类型/交付模式。
- 截止时间可空，输入/展示为北京时间；逾期仅标记，仍可领取、提交及验收。
- 公开任务由成员领取，人数可限额或不限；同人不重复领取、并发最后一名只能成功一人。发布者手动加人也受上限约束；不能把上限降到现有人数以下。
- 领取后不能自行退出，由发布者移出；移出释放名额。发布者结束领取后既有成员仍能提交及调整，不能仅因无人执行就完成。
- 指定任务支持个人、多人、多个小组及混选，直接生效，不设接受/拒绝。合并去重，只纳入注册且启用成员，排除姓名/原因明确提示。
- 小组选项仅显示名称，合并后的有效人数/排除提示仍保留；发布者不获得小组管理权，也不能在任务内单独排除仍由目标小组覆盖的人。

## 3. 动态名单

进行中的指定任务名单＝直接指定＋目标小组当前合格成员并集；入组自动加入并提醒，退组/解散/移除目标仅移除不再被其他来源覆盖者。停用成员不再执行。

完成/撤销后名单固定；人员变更保留来源、时间和参与历史。移出后不能提交，逐人成果保留但不计当前完成；重新加入不能继承移出前个人通过结果。共同成果属于本轮，提交人移出不删除。空名单需重新安排或撤销。

## 4. 成果及完成

- 提交至少包含文字、链接、文件之一；链接只保存展示，不自动抓取仓库/外部文件。
- 每份要求/每次成果最多5个附件，单个10MiB；允许pdf/txt/md/markdown/png/jpg/jpeg/doc/docx/xls/xlsx/ppt/pptx/csv。服务端校验大小及内容，不支持压缩包、可执行文件及宏专用扩展名。
- 共同交付由任一当前执行成员提交，整轮只有一个最新成果；逐人交付每人独立版本和验收，不能代交。
- 通过前可直接重提，新版本保留旧内容、作者、反馈；打回原因必填，发布者只能验收当前最新版本。重复请求和并发不能误验旧版。
- 通过后该成果本轮不能再提；要求修改不撤回已通过结果。需要重新交付时开新轮或新任务。
- 指定任务：共同成果通过或当前逐人成员全通过后整体完成；公开任务还须发布者结束领取。空名单不能完成。

## 5. 状态与管理

整体状态为进行中/已完成/已撤销；领取状态、个人成果未提交/待验收/被打回/已通过及逾期标记分别显示，说明阻塞原因。

发布者只可修改进行中任务的标题、要求、截止时间、附件及执行目标，保留变更并提醒受影响者。撤销需确认，仅可撤销进行中；撤销后停止领取、提交和验收，保留历史。已完成不直接转撤销。

完成或撤销后可重开新轮，旧名单、要求、成果及验收固定且不计新轮。公开默认保留成员，可选择是否恢复领取；指定保留来源并按当前小组合格成员重算。默认沿用截止时间，过期提示改/清除；新轮成员重新收到指派。打回重提仍在同一轮。

## 6. 消息与提醒

| 事件 | 接收人 |
| --- | --- |
| 指派、入组加入、重开 | 对应执行成员 |
| 领取、提交/重提 | 发布者 |
| 要求/对象变化、撤销 | 受影响成员；小组变化同时提醒发布者 |
| 通过/打回 | 逐人对应成员；共同当前执行成员 |
| 整体完成 | 发布者及本轮执行成员 |

仅本人可读消息。进入网站集中弹出未读有效指派，展示标题/发布者；“知道了”读展示项，“查看任务”只读该项。已读跨设备保持，失效轮次/移出/撤销不再弹出；普通更新只入列表。弹窗不代表接单。

消息分页每批200条，标已读不丢失已加载历史。删除的范围、确认及授权见[v2.2](10-PRD-v2.2.md)。

## 7. 页面及资料预览

- `/tasks`默认进行中，公开在上、指定在下；已完成/已撤销分别筛选、合并类型并标注，菜单无“全部状态”。搜索与我发布/我执行筛选保持，重开回正确分区。
- 发布页宽屏内容/执行安排双栏，手机单栏；输入16px，辅助至少14px。下拉统一主题与键盘操作，长列表可滚动，不被弹窗裁切。
- 截止时间用日历＋独立时分，快捷今天/明天/一周后/清空；选择日期默认18:00，未选日期不设截止。
- 要求支持安全Markdown，只有编辑/预览及输入提示；标题、强调、列表、引用、链接、表格、代码可手写。旧纯文字可读，HTML/脚本/危险协议不执行；不扩展到成果或工作记录。
- 已关联任务资料点击优先站内预览，保留下载；PDF、PNG/JPEG、TXT、MD支持，Office提示下载。历史资料仍可读，成果附件保持下载。
- PDF本地PDF.js逐页绘制/翻页，不执行脚本；文本/Markdown预览上限256KiB，超限提示下载；上传仍10MiB。
- 预览/下载复用成员鉴权、文件大小/SHA及清理中校验，不能公开URL或交第三方文档服务；未关联附件仅上传者可读。
- 失败明确提示并保留授权下载回退；手机可关闭和滚动，无整页溢出。删除/撤销/转让等确认居中、默认焦点取消。

## 8. 正在做的事

原成员页保留课表，分别展示本人文字记录和当前任务；个人记录不需要关联任务，不参与验收，也不修改任务状态。

- 标题1～120字、说明1～20000字，默认进行中，状态进行中/暂停/已完成；仅本人增删改、确认删除后无恢复。无文件、评论、额外提醒或特殊审核。
- 注册成员看他人全部进行中/暂停及滚动7×24小时内完成记录，区间含起点/当前时刻，排除未来。本人管理全部历史；游客和匿名全部拒绝，篡改查询不能读取他人旧完成记录。
- 完成时间由服务端状态切换确定；已完成只改文字不刷新时间，恢复后再次完成用新时间。超过7天只退出近期显示，不删除。
- 成员任务摘要取当前承担的进行中及近7天整体完成任务；排除未领取公告、撤销及已移出。个人通过不等于整体完成，重开不继承旧成果。
- 列表按更新时间倒序并分页；切换成员不串数据，空态不能断言成员没工作。

## 9. 保留与兼容

所有任务轮次、目标/名单变化、要求、成果版本、反馈及历史附件保留，关键写入审计；不提供普通成员物理删除任务或自动到期。

仅上传者能清理本人未关联文件；先标清理中、事务外删除、成功后释放额度，失败保留重试及额度。历史引用不可清理，不把附件放public。数据库与文件成套备份；发布/回退保留账号、课程、小组、任务、记录和卷。

不实现站外通知、自动排期/指派、聊天评分、子任务/模板、会议纪要、工作记录附件或回收站。容量和发布时间由维护者核定；已确认补充默认的出处见[决策包](09-v2-grill-decision-packet.yaml)。
